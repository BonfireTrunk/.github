### Open source

Small, focused Java libraries, published to Maven Central under `today.bonfire.oss`. Each one grew out of something our own software needed.

| Library | What it does | Latest | License |
| :-- | :-- | :-- | :-- |
| [**simple-object-pool**](https://github.com/BonfireTrunk/simple-object-pool) | Thread-safe, configurable object pooling with idle eviction and abandoned-object cleanup. No dependencies beyond SLF4J. | [![simple-object-pool on Maven Central](https://img.shields.io/maven-central/v/today.bonfire.oss/simple-object-pool?style=flat-square&color=e8590c&label=)](https://central.sonatype.com/artifact/today.bonfire.oss/simple-object-pool) | Apache-2.0 |
| [**bth4j**](https://github.com/BonfireTrunk/bth4j) | Background jobs on Redis or Valkey: delayed, recurring and queued tasks with lifecycle callbacks. | [![bth4j on Maven Central](https://img.shields.io/maven-central/v/today.bonfire.oss/bth4j?style=flat-square&color=e8590c&label=)](https://central.sonatype.com/artifact/today.bonfire.oss/bth4j) | MPL-2.0 |
| [**jutils**](https://github.com/BonfireTrunk/jutils) | Everyday helpers: hashing and encoding, random values, validation, country codes, context-aware parallel tasks and small web utilities. | [![jutils on Maven Central](https://img.shields.io/maven-central/v/today.bonfire.oss/jutils?style=flat-square&color=e8590c&label=)](https://central.sonatype.com/artifact/today.bonfire.oss/jutils) | Apache-2.0 |
| [**oss-parent**](https://github.com/BonfireTrunk/oss-parent) | The shared Maven parent POM behind these libraries: managed versions, a Java 21 baseline and release profiles. | [![bonfire-oss-parent on Maven Central](https://img.shields.io/maven-central/v/today.bonfire.oss/bonfire-oss-parent?style=flat-square&color=e8590c&label=)](https://central.sonatype.com/artifact/today.bonfire.oss/bonfire-oss-parent) | Apache-2.0 |

### Beyond open source

Open source is one part of what we do. Bonfire Trunk also designs, builds and runs its own software products, and the libraries above are the general-purpose pieces that came out of that work.

### Get involved

- **Contribute:** start with the [contributing guide](https://github.com/BonfireTrunk/.github/blob/prime/CONTRIBUTING.md). Every pull request includes accepting the [Contributor Agreement](https://github.com/BonfireTrunk/.github/blob/cla-v1/CLA.md) with a checkbox.
- **Report a vulnerability:** privately, as described in the [security policy](https://github.com/BonfireTrunk/.github/blob/prime/SECURITY.md). Please don't open a public issue.
- **Be kind:** everyone taking part follows the [code of conduct](https://github.com/BonfireTrunk/.github/blob/prime/CODE_OF_CONDUCT.md).
- **Say hello:** [oss@bonfire.today](mailto:oss@bonfire.today)
