# Contributing

Thanks for helping improve a Bonfire Trunk project. This guide applies to every public repository in the [BonfireTrunk](https://github.com/BonfireTrunk) organization unless the repository has its own `CONTRIBUTING.md`.

## Before you start

- **Bugs:** open an issue with the bug report form. A small example that reproduces the problem helps more than anything else.
- **New features or bigger changes:** open an issue first, so we can agree on the approach before you spend time on code.
- **Security vulnerabilities:** never in public issues or pull requests. Follow the [security policy](https://github.com/BonfireTrunk/.github/blob/prime/SECURITY.md).

## Making a change

1. Read the repository's README. It explains how to build and test that project, and any rules of its own, such as the tools it needs or when to change its version.
2. Fork the repository and create a branch from `prime`, the default branch.
3. Make your change, with tests for any new or changed behavior.
4. Build and test it the way the README describes before you push.
5. Open a pull request against `prime`, describe what changed and why, and tick the Contributor Agreement box.

Keep each pull request to one change. Small pull requests get reviewed faster.

### Versions

Leave the project's version alone unless its README says otherwise. The maintainer sets the final version and writes the changelog at release time.

## Contributor Agreement

Every pull request needs the box for the [BonfireTrunk Contributor Agreement v1](https://github.com/BonfireTrunk/.github/blob/cla-v1/CLA.md) ticked in its description. The `cla` check stays red until it is.

In short, you keep the copyright in your work and give the maintainer a broad license to use it, including under other licenses, open source or proprietary. Please read the agreement itself; its text is what counts.

## Review and merge

- Automated checks must pass. On your first contribution, a maintainer may need to approve them before they run.
- Pull requests are squash-merged, and the pull request title becomes the commit title on `prime`, so make it a clear one-line summary.

## Code of conduct

Everyone taking part follows the [code of conduct](https://github.com/BonfireTrunk/.github/blob/prime/CODE_OF_CONDUCT.md).
